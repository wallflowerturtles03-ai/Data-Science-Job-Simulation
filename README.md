# Data Science Job Simulation

This repository contains a Python-based data science job simulation focused on building a practical analytics workflow from raw data to a machine learning solution. The project is organized as a series of Jupyter notebooks covering data preparation, exploratory analysis, feature engineering, and model development.

## Project Overview

The simulation mirrors a typical data science workflow used in industry and academia:

- Cleaning and preparing raw datasets
- Performing exploratory data analysis (EDA)
- Identifying patterns and anomalies in the data
- Engineering informative features for modeling
- Building and evaluating predictive models
- Drawing actionable conclusions from model output

## Repository Structure

- `Task_2.ipynb` – notebook covering an early project task, likely focused on data exploration or preprocessing
- `Task 3 - feature_engineering (1).ipynb` – notebook for feature creation and transformation
- `Task 4 - modeling_starter (1).ipynb` – notebook for initial model training and evaluation
- `README.md` – project overview and setup instructions
